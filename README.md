# Dashboard Epidemiologi

Website statis sederhana menggunakan HTML, CSS, dan JavaScript.

## Menjalankan di komputer
1. Buka folder ini di Visual Studio Code.
2. Buka `index.html` di browser, atau gunakan extension Live Server.
3. Edit data contoh pada `script.js`.

## Publikasi gratis dengan GitHub Pages
1. Buat akun GitHub.
2. Buat repository baru, misalnya `website-epidemiologi`.
3. Upload `index.html`, `style.css`, dan `script.js`.
4. Masuk ke **Settings → Pages**.
5. Pada Source pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu Save.
7. Setelah proses selesai, GitHub memberikan alamat website.

Catatan: versi ini adalah website statis. Data contoh berada di `script.js` dan belum menggunakan database/server.
